# Surat Tidak Hadir Sekolah

Web app mudah untuk isteri/ibu bapa isi borang ketidakhadiran sekolah dan **auto generate PDF** terus untuk print.

## Cara Guna

1. Buka link ni di telefon atau komputer:  
   **https://reza5208.github.io/surat-tidak-hadir-sekolah/**

2. Pilih nama anak (Zahra Adawiyah / Uyun Al Dhuha / Qaid Ukail / Indah Rugayyah)
3. Isi kelas, tarikh, alasan, nama ibu bapa, no telefon & nama sekolah
4. Klik **Jana PDF & Muat Turun**
5. PDF terus masuk folder Download → print je

## Ciri-ciri

- Dropdown nama anak (siap ada 4 nama)
- Mobile-friendly (senang isi kat telefon)
- Generate PDF A4 yang formal
- Tak perlu login
- Boleh guna offline selepas load sekali

## Nama Anak yang Ada

- Zahra Adawiyah
- Uyun Al Dhuha
- Qaid Ukail
- Indah Rugayyah

## Teknologi

- Pure HTML + CSS + JavaScript
- jsPDF (generate PDF di browser)
